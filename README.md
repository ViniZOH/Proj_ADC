Este repositório trata do uso do conversor AD na placa Bitdoglab, que é microcontrolada pelo Raspberry Pi Pico W. Para execução do projeto basta ecompilar o código e carregar na placa, ou carregar diretamente o arquivo .uf2, que já se encontra na pata "build".

O código terá mais comentpárioas, a fim de ajudar na visualização do fluxo do programa, em breve !
